Changes since the prior report

This report is a re-evaluation. The prior report is dated August 30, 2026, published at https://brianbeals.com/conformance-report.html. Every page and document below was evaluated again against the site as it stood on October 8, 2026.

What changed on the site

  • 20 pages were evaluated in the prior report and 23 in this one.
  • Pages added since the prior report: /writing/everybody-got-a-license, /writing/sixty-cents-a-year, /writing/who-could-afford-to-find-out.
  • 6 of the 6 published documents were revised after the prior scan and were validated again: Accessibility practice, ADA Title II; Accessibility practice, federal Section 508; Federal, SDVOSB; Florida state and local, VBE; Accessibility practice, Section 504 healthcare; Accessibility practice, Maryland CATS+.
  • Evaluated set widened from 20 pages to 29: three essays published since August 30, and the six HTML capability statements, which the crawl had never reached because they were listed in no sitemap.
  • Screen reader testing added: a full VoiceOver pass in Safari on 12 pages, which decided 1.3.1, 2.4.1, 2.4.6, and 4.1.2.
  • Capability statements fixed before this report: dark-mode heading and banner contrast (1.4.3), reflow at 320 pixels (1.4.10), and a malformed definition list (1.3.1). Each was rescanned clean.
  • Essay byline: the brand mark is now hidden from assistive technology, as it is everywhere else on the site, so the author's name is no longer announced twice.
  • Voice critique tool: the copy confirmation is now announced through a status message (4.1.3).
  • Site map: the three new essays, this report, and the six capability statements were added to the site map or the XML sitemap, and every page now links the site map, this report included (2.4.5).

What changed in the verdicts

  • No criterion changed its conformance level.

What the screen reader pass added

A screen reader pass across 12 page(s), new in this evaluation. The criteria it decided:

  • 1.3.1 Info and Relationships: previously decided by the scan and the keyboard checklist; the screen reader pass confirms the prior Supports.
  • 2.4.1 Bypass Blocks: previously decided by the scan and the keyboard checklist; the screen reader pass confirms the prior Supports.
  • 2.4.6 Headings and Labels: previously decided by the scan and the keyboard checklist; the screen reader pass confirms the prior Supports.
  • 4.1.2 Name, Role, Value: previously inferred from the accessibility tree; the screen reader pass confirms the prior Supports.

Applicable standards

WCAG 2.1 Level A and AA, all 50 criteria. Section 508 incorporates WCAG 2.0 Level AA, a strict subset, so conformance below satisfies it. ADA Title II adopts WCAG 2.1 Level AA directly. Level AAA was not evaluated.

Evaluation methods used

  • Automated rule checking with axe-core 4.10.2, plus checks it does not carry: contrast under both color schemes, reflow measured by geometry at a real 320 pixel viewport, and focus visibility under a real keyboard press.
  • 6 document(s) validated against ISO 14289-1 (PDF/UA-1) with veraPDF, the reference validator. Only validator rules that map to a WCAG success criterion are reported here; PDF/UA is a wider standard than the one this report applies.
  • 23 criteria that cannot be settled by the automated rules were decided by a scripted keyboard pass in Chromium and inspection of the rendered pages and the site's source, by Claude Code, for Brian Beals, LLC on 2026-10-08. Recorded in verify-2026-10-08.yml, retained with the scan findings so this report can be reproduced.
  • Screen reader testing with VoiceOver on macOS 27.0 in Safari 27.0.1, by Brian Beals on October 8, 2026, across 12 page(s). Each page was checked for reading from the top, the skip link, landmark navigation, heading navigation, the links list, and how the brand mark is announced. This was a full pass: every check in the protocol was run on every one of those pages, none skipped or sampled. This pass decided 1.3.1, 2.4.1, 2.4.6, 4.1.2; results by page are tabled below.
